# AURA EDGE desktop design

The supplied Home image governs the panel order, navigation, room photography and smoked charcoal surfaces. The 17-screen preview informs the supporting navigation and view hierarchy. The desktop concept governs the ivory robot, compact island and menu treatment.

Use warm charcoal surfaces with light ivory type and muted lime for selected controls, active capture and verified actions. The CSS establishes a local Segoe UI typography stack, consistent focus outlines and responsive Home panel proportions. Rooms use bundled WebP photography generated for this project in the reference style. The robot is an original QML canvas drawing. The project uses local interface icons and system fonts.

Availability, device capabilities, schedules, activity time, energy estimates and notifications come from the backend. Idle audio is flat. The UI displays the current turn state when there is no measured playback level. All imagery represents the simulator.
