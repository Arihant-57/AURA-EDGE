## Packaging and competition rules

The inspected source-only Git archive contained the source, launcher, database configuration template and dependency lists. Preparing a fresh laptop still requires the frontend build, runtime dependencies, cached container image and locally licensed model files. Clean installation on an unprepared disconnected laptop remains unverified. The delivery packaging script adds the compiled frontend and scoped shutdown helper. An extracted copy launched the native desktop, started its owned backend against disposable PostgreSQL, served the dashboard over HTTP, returned a verified clock answer, exited cleanly via the shutdown script and released its listener. It borrowed the installed Python environments, database engine, Ollama and models.
